# Contributing

Thanks for your interest in improving OpenClaw AI Hub!

## How to Contribute

### Report Issues
- Use GitHub Issues for bugs, feature requests, or documentation improvements
- Include your macOS version, hardware (RAM), and OpenClaw version
- For security issues, please use private disclosure (do not open a public issue)

### Pull Requests
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-improvement`)
3. Make your changes
4. Test on a real setup if possible
5. Submit a PR with a clear description of the change

### What We're Looking For
- Setup improvements and bug fixes
- Better documentation and troubleshooting entries
- New LaunchAgent templates
- Support for additional platforms (Linux)
- Translations

### Guidelines
- Keep documentation practical — based on real-world usage, not theory
- Be honest about limitations (cloud vs. local, model capabilities)
- No personal data or API keys in any files
- Shell scripts should include error handling and clear output

## Code of Conduct

Be respectful, be helpful, be honest. We're here to help people run AI infrastructure safely.
